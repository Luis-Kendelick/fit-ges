Aplicativo de Gerenciamento para Personal Trainers (FitGes)

# Visão Geral
Um aplicativo web (e futuramente mobile) para personal trainers gerenciarem seus alunos, aulas, e pagamentos.

# Principais Funcionalidades
- Gestão de alunos (cadastro, edição, remoção)
- Calendário de aulas com visualização semanal/mensal
- Gerenciamento de planos e pagamentos
- Sistema de notificações
- Dashboard de métricas financeiras

# Tecnologias
- Frontend: React 18 + TypeScript, TailwindCSS, ShadCN, React Router
- Backend: Node.js e Nest.js
- Mensageria: Socket.io
- Infraestrutura: Vercel (front), Railway (back), Supabase (banco de dados)
